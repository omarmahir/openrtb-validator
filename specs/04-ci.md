# Spec 4 — CI quality gate

GitHub Actions workflow at .github/workflows/ci.yml.

## Triggers
Every push and every pull request, all branches.

## Steps (in order, cheapest first)
1. `cargo fmt --all -- --check`
2. `cargo clippy --all-targets -- -D warnings`
3. `cargo test --all-targets`

## Environment
- ubuntu-latest, stable toolchain with rustfmt and clippy components
- Cache ~/.cargo/registry, ~/.cargo/git, and target/, keyed on Cargo.lock

## Notes
- `--all-targets` matters: without it clippy skips test code
- Linux runner differs from the macOS dev machine, which is deliberate —
  it catches platform-specific assumptions

## Acceptance
Actions tab shows a green check after push.
